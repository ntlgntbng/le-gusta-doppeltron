### **The Origin Story**

It started simple enough: a pair of **stock Cerwin-Vega DX-9 floorstanding towers** powered by a single **Phonic MAX1500 amplifier**. 

Then audio addiction set in. 

What began as a straightforward 2-channel living room setup rapidly mutated into an absolute monster:
1. **The DXW15 Exorcism:** The stock DXW15 woofers were ripped out and swapped for heavy-duty **Cerwin-Vega 152WR cast-aluminum frame woofers**.
2. **Subharmonic Reinforcements:** A pair of **DB Drive 12" subwoofers** were added to handle sub-octaves generated by a **dbx 120XP** synthesizer.
3. **The Crown Takeover:** The original Phonic MAX1500 was relegated strictly to dedicated sub-bass duty, while a high-damping **Crown Power-Tech 3 (PT-3)** took over main power amplification.
4. **Xover Rebuild:** The internal stock passive crossovers were stripped and rebuilt into custom 3-tier acrylic crossover towers (featuring Jantzen C-Coil toroids, Mundorf pure copper foil coils, and Bevenbi, Solen and Mundorf film caps), fed by an insane over-the-top **10-hop pro-audio processing rack**.

**`le-gusta-doppeltron`** is the exact zero-dependency, browser-based **cybernetic digital twin** of this living-room monstrosity.

### **Core Workstation Features**

* **Interactive 2D Vector Crossover Blueprint:** Schematic mapping every capacitor bank, toroidal inductor, foil coil, resistor L-pad, and mechanical T-knot junction with a real-time PCB neighbor topology inspector.
* **10-Hop Signal Processing Stack:** Granular front/rear panel control for the entire analog/digital processing chain with **independent hardware state management and individual bypass controls**:
  1. **Furman PL-PRO DMC** — AC Power Grid Isolation
  2. **Fosi Audio ZD3 DAC** — 24-bit / 96kHz Digital Core
  3. **dbx 3BX** — Multi-Band Dynamic Range Expander
  4. **dbx 120XP** — Subharmonic Synthesizer (28–36Hz Sub-Octaves)
  5. **DOD SR231QXLR** — Active 31-Band Surgical Graphic EQ
  6. **dbx 1066** — PeakStopPlus Brickwall Limiter (Horn Diaphragm Protection)
  7. **BBE 882i** — Temporal Phase Realignment Engine
  8. **BDS PP-31 Spectrum Analyzer** | **UniSync PMS-1** — Visual RTA Telemetry Pass-Throughs
  9. **Crown Power-Tech 3** — 540W RMS Class AB Main Drive
  10. **Phonic MAX1500** — 1500W Parallel-Mono Subwoofer Drive
* **Live DSP Engine & 60fps Visualizers:** Built-in test tone/pink noise generator with 31-band FFT spectrum analyzer and time-domain oscilloscope running on a smooth 60fps canvas loop.
* **Math Physics Lab:** Live typeset Linkwitz-Riley equations using KaTeX for real-time calculation of cutoff frequency ($f_c$), constant-$Z$ L-Pad resistor values ($R_1, R_2$), and AC reactance ($X_L, X_C$).
* **Virtual Multimeter (DMM):** Pre-power diagnostic test bench for continuity, resistance (DCR), and short-circuit auditing.
* **2D Room Acoustics Simulator:** Boundary loading SPL generator modeling wall/corner distance, axial room modes, and boundary gain boosts up to +9 dB.

### **Quick Start**

No `npm install`, build tools, or complex dependencies required. 

1. **Clone the repo:**
```bash
git clone https://github.com/ntlgntbng/le-gusta-doppeltron.git
```

2. **Launch the Workstation:**
Double-click `index.html` or serve it locally:
```bash
python3 -m http.server 8000
```

3. **Open in Browser:** Navigate to `http://localhost:8000`.
